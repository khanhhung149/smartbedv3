## [1.0.0] — 2026-05-03

### ✨ Features

#### Multi-Language Support (EN + Vietnamese)
- **Completion Date:** 2026-05-03
- **Scope:** Full app translation with 65+ localization keys
- **Impact:** App now accessible to both English and Vietnamese-speaking users
- **Architecture:**
  - ARB-based localization files (`app_en.arb`, `app_vi.arb`)
  - Riverpod-backed `LocaleNotifier` for state management
  - Persistent locale storage via `flutter_secure_storage`
  - Locale-aware date formatting using `intl` package
  - Language switcher UI in Settings → Appearance section
- **Coverage:**
  - Onboarding flow (6 screens)
  - Authentication (5 screens)
  - Device management (8 screens + widgets)
  - History visualization (1 screen)
  - Alerts (3 screens)
  - Settings (1 screen)
  - Shared components and dialogs
- **Generated Files:**
  - `lib/l10n/app_localizations.dart` (generated by Flutter)
  - `lib/l10n/app_localizations_en.dart` (generated)
  - `lib/l10n/app_localizations_vi.dart` (generated)
- **Infrastructure:**
  - `intl: ^0.20.2` dependency added
  - `flutter_localizations: sdk` enabled
  - `l10n.yaml` configuration created
  - `pubspec.yaml` updated with `generate: true`

### 🔧 Technical Changes

#### Locale Provider & State Management
- **File:** `lib/shared/providers/locale_provider.dart`
- **Implementation:**
  - `LocaleNotifier` extends `StateNotifier<Locale?>`
  - Persists selected locale to secure storage on change
  - Includes `mounted` checks and try-catch error handling
  - Auto-loads persisted locale on app initialization

#### App Router Integration
- **File:** `lib/app.dart` (`_RouterApp` widget)
- **Changes:**
  - `_RouterApp` is `ConsumerStatefulWidget` with memoized `GoRouter`
  - Router instance only recreates on JWT token change (not on locale change)
  - `MaterialApp.router` receives `locale: ref.watch(localeProvider)`
  - Loading and error states include `localizationsDelegates`
  - Preserves navigation stack during language switching

#### Screen Translations (Phase 3)
- **Onboarding & Auth:**
  - `onboarding_screen.dart` — all 4 sleep slides translated
  - `onboarding_sleep_slide.dart` — localized slide content
  - `login_screen.dart` — login form labels, buttons, errors
  - `register_screen.dart` — registration form fields
  - `verify_email_screen.dart` — email verification instructions
  - `forgot_password_screen.dart` — password reset request flow
  - `reset_password_screen.dart` — new password entry

- **Device Management:**
  - `ble_scan_screen.dart` — BLE scanning instructions
  - `ble_provision_wifi_screen.dart` — WiFi credential entry
  - `ble_provision_pairing_screen.dart` — pairing status messages
  - `ble_provision_success_screen.dart` — success confirmation
  - `devices_my_section.dart` — device list, relative timestamps
  - `devices_pending_invites_section.dart` — invite actions
  - `device_detail_info_card.dart` — metric labels and units

- **History & Alerts:**
  - `history_screen.dart` — sleep data visualization
  - `alerts_screen.dart` — alert list view
  - `alerts_app_bar.dart` — filtering and sorting UI
  - `alert_detail_screen.dart` — individual alert details

- **Settings & Sharing:**
  - `settings_screen.dart` — all sections translated
  - `invite_family_sheet.dart` — sharing dialog

#### Language Switcher UI
- **File:** `lib/features/settings/settings_screen.dart`
- **Location:** Settings → Appearance section (below theme selection)
- **Component:** `_LanguagePickerSheet` bottom sheet
- **Behavior:**
  - Displays current language (English / Tiếng Việt)
  - Tapping opens bottom sheet with language options
  - Selection persists via `localeProvider`
  - App updates all text without navigation stack loss

#### Locale-Aware Formatting
- **Date Formatting:** `DateFormat.MMMd(ref.read(localeProvider)?.languageCode)`
- **Relative Time:** Converted to Vietnamese when locale is `vi`
- **Examples:**
  - EN: "May 3" / "2 hours ago"
  - VI: "3 Tháng Năm" / "2 giờ trước"

#### Code Quality
- **Linting:** `flutter analyze` passes with zero issues
- **Architecture:** Riverpod + GoRouter integration stable across locale changes
- **Error Handling:** All async operations include try-catch and mounted checks
- **Storage:** Secure storage for locale preference (non-sensitive, but best practice)

### 📝 Documentation

#### Created
- `docs/project-roadmap.md` — Multi-language support documented in Phase 5

#### Updated
- `pubspec.yaml` — Added intl dependency and generate flag

### 🐛 Bug Fixes & Improvements

#### Locale Provider Robustness
- Added `if (!mounted)` guard before `setState()` calls
- Wrapped `await` calls in try-catch to prevent exceptions
- Proper error logging for failed storage operations

#### Router Stability
- Memoized router in `_RouterApp.initState()` to preserve navigation stack
- Router recreates only on JWT token changes, not locale changes
- Both loading and error states properly include localization delegates

### Commit Message Convention
Use conventional commits:
- `feat:` — New feature
- `fix:` — Bug fix
- `refactor:` — Code reorganization (non-feature)
- `docs:` — Documentation updates
- `test:` — Test additions or fixes
- `chore:` — Build, CI/CD, dependencies
